Лицензии и 3D

Автомобиль «Ровный ход»

Авторская программная геометрия Rovny Touring, созданная для этого шаблона. Модель, SVG-постер и генератор передаются под CC0 1.0: можно использовать коммерчески, изменять и распространять вместе с исходниками. Логотип не изображает автомобильную марку. Сторонних текстур, платных моделей и брендированных автомобилей нет.

Скачать GLB. Исходная геометрия находится в src/lib/car-geometry.mjs, генератор — scripts/generate-model.mjs. После изменения модель можно снова экспортировать.

Библиотеки

Three.js, React, Next.js, React Three Fiber и Drei — MIT. Иконки Lucide — ISC. Обработка изображений sharp — Apache 2.0. Полные лицензии зависимостей поставляются в их пакетах и перечислены в docs/LICENSES.md.

Бесплатные источники

При разработке проверен набор Kenney Furniture Kit под CC0 для первоначального задания о мебели. После смены тематики на автосервис эти ассеты не используются. В этой сборке все детали автомобиля созданы из исходной геометрии.
